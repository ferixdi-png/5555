# Куда загружать реальные видео

Загружай все ролики именно сюда:

`public/videos/`

Сайт автоматически ищет до 20 MP4-файлов с точными именами:

- `video-01.mp4`
- `video-02.mp4`
- `video-03.mp4`
- ...
- `video-20.mp4`

Можно начать хоть с 3 роликов: отсутствующие номера сайт просто не покажет.

## Чтобы сохранить максимально красивую картинку

- Загружай оригинальный файл **1920×1080 (1080p)**, если генератор отдал именно его.
- Формат: **MP4**.
- Для максимальной совместимости с браузерами желательно **H.264 + AAC**.
- Не прогоняй ролик через Telegram перед загрузкой — Telegram может сжимать медиа. Бери исходный файл генерации.
- Не пересохраняй ролик несколько раз через редакторы без необходимости.
- Сервер этого сайта **не перекодирует и не уменьшает разрешение**: посетителю отдаётся тот MP4, который лежит в этой папке.
- Браузер может визуально масштабировать ролик под размер карточки, но сам файл остаётся исходным.

## Как загрузить через GitHub в браузере

1. Открой репозиторий `ferixdi-png/5555`.
2. Открой папку `public`.
3. Открой папку `videos`.
4. Нажми **Add file → Upload files**.
5. Перетащи ролики с уже правильными именами `video-01.mp4`, `video-02.mp4` и т.д.
6. Нажми **Commit changes**.
7. Render автоматически увидит новый commit и обновит сайт, если Auto-Deploy включён.

## Размер файлов

20 исходных 1080p-видео могут весить много. Для комфортной загрузки страницы желательно разумно держать битрейт, но **не нужно уменьшать разрешение ради сайта**. Если конкретный ролик слишком тяжёлый для загрузки через веб-интерфейс GitHub, можно загрузить его через обычный Git или аккуратно оптимизировать битрейт с сохранением 1080p.
