# Как добавить видео

Сайт автоматически ищет до 20 MP4-файлов с такими именами:

- `video-01.mp4`
- `video-02.mp4`
- ...
- `video-20.mp4`

Загружай свои ролики прямо в эту папку `public/videos/`.
Несуществующие номера сайт просто скрывает.

Рекомендации:
- MP4 / H.264 для максимальной совместимости.
- Для быстрой загрузки старайся держать каждый ролик примерно до 10–20 МБ.
- Через веб-интерфейс GitHub отдельный файл лучше держать до 25 МБ.
- Если файл тяжелее, предварительно сожми его или загружай через Git.
