# Автоаудио

Если хочешь фоновую аудиозапись, загрузи сюда файл с точным именем:

`voice.mp3`

Итоговый путь должен быть:

`public/audio/voice.mp3`

Сайт пытается запустить запись автоматически без отдельной кнопки. Часть браузеров может блокировать autoplay со звуком до первого взаимодействия пользователя — это ограничение браузера, а не Render.
